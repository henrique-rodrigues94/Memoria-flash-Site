Perguntas frequentes

Preciso fazer login para usar os flashcards?

Sim. A área de estudos é privada para proteger seus baralhos, cards e progresso.

O que fica público para o Google?

Esta página institucional, com informações gerais sobre o MemoriaFlash. Dados pessoais e conteúdos privados não são apresentados nesta página.

Posso acessar meus estudos pelo computador?

Sim. O MemoriaFlash possui uma versão web para acessar sua área de estudos pelo navegador.
